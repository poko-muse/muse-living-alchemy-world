## 1. 使い方（リレー手順）

作画エンジンに GPT（ChatGPT の画像生成）を使い、ポコが監督（指示・QA・データ整合・配置）を担う方式。

1. **Fuu → ChatGPT**: 第2節の「共通指示文」を貼り、基準見本 `assets/visual-samples/reference_item_design_sample.jpg` を一緒に渡す。
2. **Fuu → ChatGPT**: 第3節の個別指示文を **1点ずつ** 貼って生成する（1回の会話で共通指示文を先に送っておけば、以降は個別指示文だけでよい）。
3. **Fuu → ポコ**: 生成された画像を、このチャット（フラスコワールド）にそのまま送る。ファイル名の付け替えや加工は不要（ポコ側で行う）。
4. **ポコ → Fuu**: 第5節の観点で QA し、「採用」か「修正指示（第4節の定型文から選ぶ＋具体的な直しどころ）」かを返す。
5. **Fuu → ChatGPT**: 修正指示を貼って再生成し、できた画像を再度ポコへ。採用が出たらその点は完了。
6. バッチの全点が採用になったら、ポコが正式配置（`site/assets/items/mat_XXX.webp`）と commit を行い、結果を報告する。

注意:
- GPT 側には世界の正式データそのものは渡さない。本パックの指示文に必要な特徴だけを抜き出してある。
- 未発見素材（星屑粉 mat_011）はこの方式でも描かない（第2節の世界ルール参照）。バッチ3で「シルエット＋？」のみ扱う。

## 2. 共通指示文（最初にそのまま貼る）

```text
これから、架空の錬金術ファンタジー世界「フラスカリア」の公式図鑑用に、アイテムのイラストを1点ずつ描いてもらいます。添付した画像が画風の基準見本です。全ての絵をこの画風で統一してください。


・『キュイジニア』のような、丸みのある、かわいらしい手描きイラスト
・世界観は『アトリエ』シリーズのような、温かみと幻想性のある錬金術ファンタジー
・造形は少しデフォルメされた、ぽってりしたシルエット
・質感は柔らかな厚塗り、強めのツヤとキラキラの星の輝き、手描き感のあるはっきりした輪郭（2026-11-19 の新テイスト移行で更新。基準は火種の種の絵）
・色彩は鮮やかで温かい色合い（パステルのように淡く・マットにしすぎない）
・素材の魅力を伝える小物（袋・タグ・容器など）を添えてよい。ただし文字は入れず、絵柄のマークのみ可
・かわいらしさを重視しつつ、錬金術の世界らしい神秘性と素材の魅力を失わないこと
・実在のゲームのキャラクター・アイテム・ロゴなどの直接の模倣はしないこと（画風の特徴だけを参考にすること）


・描くのは指定したアイテム単品のみ。中央に大きく配置する
・背景は無地のクリーム色のみ。風景、建物、人物、他のアイテムは描かない
・画像の中に文字、ロゴ、署名、枠、リボン、カードなどの装飾を一切入れない
・羊皮紙カードや名前リボンなどの「図鑑画面」の装飾は後でこちらで付けるので、絵には含めない


・まだ発見されていない素材は描かない（描いてよい素材はその都度指定する）
・指定された素材の産地・性質と矛盾する描写はしない（例：水の素材に炎をまとわせない）

準備ができたら「準備OK」とだけ返事をしてください。次に描いてほしいアイテムを1点ずつ指定します。
```

## 3. バッチ1（素材A）の個別指示文

対象（`docs/visual_production_plan.md` バッチ1）: mat_001 しずく草 / mat_002 コルク樹皮 / mat_003 くるり丸石 / mat_004 映し湖の朝露
各文は共通指示文を送ったあと、1点ずつそのまま貼って使う。特徴はすべて `world/materials.json` の実データ（カテゴリ・産地・性質・属性・採取条件）から読み取れる範囲のみで、データに無い外見設定は足していない。

### 3-1. mat_001 しずく草

データ: 植物／産地 くるり川沿い／属性 水／性質 保水・柔軟／朝、川沿いで採取

```text
1点目をお願いします。「しずく草」を描いてください。
川沿いに生える水属性の草です。丸く柔らかい葉が数枚集まった姿で、保水性が高いことを表すように、葉の先や表面に丸い水滴をたたえ、水滴が朝の光できらめく様子にしてください。水辺の清涼感と、薬草らしい穏やかな魅力を両立させてください。
```

### 3-2. mat_002 コルク樹皮

データ: 樹皮／産地 コルク森／属性 土／性質 断熱・軽量／落皮のみ採取（幹を傷つけない）

```text
2点目をお願いします。「コルク樹皮」を描いてください。
コルクの木から自然に剥がれ落ちた樹皮です。幹は描かず、剥がれた樹皮の塊だけを描いてください。コルクらしい小さな孔のある温かみのある質感で、軽量であることが伝わる軽やかな造形にしてください。土属性の素朴さと、容器や建材に使える丈夫さの両方を感じさせてください。
```

### 3-3. mat_003 くるり丸石

データ: 鉱物／産地 くるり川／属性 土／性質 円滑・重し／川の浅瀬で採取

```text
3点目をお願いします。「くるり丸石」を描いてください。
川の浅瀬で水に磨かれた、丸く滑らかな石です。角のないぽってりした丸みと、濡れたような適度な光沢で「円滑」な質感を表してください。錬金釜の重しに使える、ずっしりした安定感も感じさせてください。石は1〜3個を重ねた程度の、ささやかなまとまりでお願いします。
```

### 3-4. mat_004 映し湖の朝露

データ: 液体／産地 映し湖／属性 水／性質 映写・冷却／日の出前のみ採取可能

```text
4点目をお願いします。「映し湖の朝露」を描いてください。
湖のほとりで日の出前にだけ集められる朝露を、小さなガラス瓶に入れた姿で描いてください。露には周りの景色を映す性質があるので、液体の表面に朝の空や湖の色がほんのり映り込むような、神秘的な透明感にしてください。冷たく澄んだ水属性の魅力と、夜明け前の静けさを感じさせてください。
```

## 4. 修正依頼の定型文

ポコの QA で差し戻しになった場合に、ChatGPT へそのまま貼って使う。該当するものを選び、必要なら末尾に具体的な一言を足す。

**画風が淡すぎる（パステル寄り）**
```text
色が淡く、パステル寄りになっています。基準見本と同じくらいまで、色の鮮やかさと厚塗りの濃さを上げてください。他の要素は変えないでください。
```

**画風が濃すぎる（原色・ギラつき寄り）**
```text
色が強すぎて原色っぽくなっています。鮮やかさは保ったまま、基準見本のような優しい色合いに落としてください。他の要素は変えないでください。
```

**輪郭・質感が画風と違う（硬い／写真寄り／ベタ塗り）**
```text
質感が基準見本と違います。柔らかな厚塗りと、手描き感のある輪郭に戻してください。硬い角や写真のような質感は避けてください。
```

**造形がぽってりしていない**
```text
造形が細く・硬くなっています。もう少しデフォルメして、ぽってりした丸いシルエットにしてください。
```

**文字・装飾が混入した**
```text
画像の中に文字（または装飾）が入っています。文字・ロゴ・署名・枠・リボンは一切入れず、アイテム単品とクリーム色の背景だけにしてください。
```

**形式違反（背景・他のものが描かれた）**
```text
背景や他のものが描かれています。背景は無地のクリーム色のみ、描くのは指定したアイテム単品だけにしてください。
```

**データと違う特徴が描かれた**
```text
指定した素材の特徴と違う描写があります。（ここに具体的に：例「この素材は水属性なので、炎の表現を消してください」）指定した産地・性質に合う表現だけに直してください。
```

**神秘性が足りない**
```text
かわいらしさは良いのですが、錬金術素材らしい神秘性が弱いです。光沢、発光、結晶感など、素材の不思議な魅力を少しだけ足してください。派手にしすぎないでください。
```

**画風ドリフト時のリセット（2026-11-19 の教訓）**
修正指示の文言（例：「大まかな厚塗り」「マットに」）が会話全体の画風アンカーを引っ張り、以降の絵が別テイストに寄ることがある（火種の種の描き直し以降に発生）。画風が変わったと感じたら、その会話で粘らず、**新しい会話を開き、参照シートを再添付して共通指示文から貼り直す**。個別の質感修正は「その素材だけ」の話だと明示する。
また、気を抜くと描き込み過多・画風の緩やかなドリフトが起きるため、**3〜4点ごとに基準見本（新テイストでは reference_style_v2_hidane.jpg ＝火種の種の絵）を再添付して「画風は添付の見本に合わせて」と添える**（2026-11-19 Fuu の提案で運用ルール化）。新会話の開始時は必ず添付する。
