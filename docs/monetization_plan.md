# マネタイズ計画 — 図鑑・書籍方向

決定: 2026-11-19、Fuuがマネタイズの方向として「図鑑・書籍」を選択した。
本書は計画であり、販売開始・外部サービスへの登録はまだ行っていない（いずれも実施時にFuuの承認が必要）。

## 方針

- **本命は図鑑・書籍**。この世界の資産は、構造化データ（`world/*.json`）と履歴（`world/history.jsonl`）として毎日積み上がる「検証可能な歴史」であり、それを編集して届ける形が最も資産を活かせる。
- **GitHub Pages（公式サイト）は展示・集客の場**であり、日次の様子・基本図鑑・住民名鑑は今後も無料で公開し続ける。
- **販売は外部チャネルで行う**（有料note / BOOTH 等を想定）。
- GitHub Pages で商取引を主目的にしない理由: GitHub Pages の利用条件上、オンライン販売や商用サービスの運営を主目的とする利用は想定されていない（`config/publication_policy.json` の `github_pages_note` 参照）。そのため、決済・販売機能は Pages には置かず、販売が必要になった時点で外部チャネルへ分離する。万一、商取引がプロジェクトの主目的になる規模まで育った場合は、公開基盤そのものの移行を検討する。

## 商品設計:『フラスカリア錬金術図鑑 Vol.1』

| 項目 | 内容 |
|---|---|
| 対象期間 | フラスコ暦 0001-01-01 〜 0001-01-30（世界の30日目が処理された時点） |
| 到達見込み | 現実の暦で 2026-12-17 頃に 0001-01-30 が処理される見込み（現実1日 = 世界1日の換算。自動運営が止まった場合はその分ずれる） |
| 想定価格 | 300〜500円（発売時にFuuの承認を得て確定する。ここでは未確定） |
| 形態 | Markdown 原稿を `engine/compile_encyclopedia.py` で自動編纂し、販売チャネル向けに整形する |

### 収録内容

- 錬金五法則（等価循環／属性共鳴／安定度／知識の門／代償の残響）
- 素材図鑑
  - **発見済み素材のみ完全収録**（性質・属性・安定度・産地・採取条件・用途・市場価値）
  - **未発見素材は「未発見」として存在だけを記載**する。性質・用途などを推測で書かない（知識の門の法則に従う）
- レシピと実験記録
  - レシピは状態（既知／研究中／仮説）を明示し、仮説は未検証であることを区別する
  - 実験記録は `world/history.jsonl` の実験実績のみに基づき、**成功・失敗の両方を履歴どおりに**載せる。記録にない成功は書かない
- 住民名鑑（正式台帳 `world/residents.json` に基づく）
- 30日間の歴史年表（`world/history.jsonl` の出来事を時系列で）
- 街と地理（ソコノマチと施設、フラスカリアの地形）
- ポコの編者あとがき（枠を用意し、発売版で編者が記す）

## 無料 / 有料の線引き

- **無料のまま**: 公式サイトの日次情報（現在の様子・最新ニュース）、基本図鑑（素材名と概要）、住民名鑑、歴史年表の閲覧。
- **有料（書籍版）の付加価値**: 無料情報の寄せ集めではなく、次を付加価値と定義する。
  - **編集**: 期間ごとに区切り、世界の変化を追える形に再構成すること
  - **解説**: 法則と出来事の関係、素材とレシピのつながりなど、データ単体では読み取れない文脈を付けること
  - **時系列の物語化**: 30日分の出来事を、実験の成否や在庫の変動を含めて一つの流れとして読める形にすること
  - **実験の考察**: 成功・失敗の判定理由（安定度や確率）を読み解き、次に何が起きそうかを仮説として（発見とは区別して）記すこと

## ロードマップ

- **Phase A — 歴史と読者を貯める（〜 世界30日目）**
  - 日次自動運営を継続し、履歴を積み上げる。公式サイトで無料公開を続ける。
  - 図鑑の編纂基盤（`engine/compile_encyclopedia.py`）と見本（Vol.0 プレビュー）を用意し、編纂手順を確立しておく。
  - この段階では販売しない。
- **Phase B — Vol.1 編纂・発売（30日目到達後）**
  - 0001-01-01 〜 0001-01-30 の原稿を生成し、解説・考察・あとがきを加えて Vol.1 を仕上げる。
  - **販売チャネルの開設（有料note / BOOTH 等への登録）と価格確定・発売は、その時点で改めて Fuu の承認を得てから行う。**
- **Phase C — 長編化の検討（90日目頃）**
  - 90日分の歴史が貯まったら、季単位の物語編『フラスカリア創世記 第1季』の Kindle 化を検討する。
  - 実施可否・チャネル登録は Phase B と同様に承認事項とする。

## 正直な収益見立て

- 初期の収益は **月数百〜数千円規模**を想定する。大当たりを狙う計画ではない。
- 主目的は収益そのものよりも、**再現性のある編纂手順と、毎日増え続ける創作資産（歴史データ）の蓄積**にある。図鑑は Vol.2, Vol.3… と期間を区切って継続でき、資産が増えるほど1冊あたりの編纂コストは下がる。
- 売れ行きが想定を下回っても、無料公開と世界の運営自体は継続できる設計にする（固定費ゼロを維持する）。
