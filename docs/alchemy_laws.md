# 錬金術の五法則 — フラスカリア

錬金術は万能の魔法ではなく、法則と代償を持つ技術である。

1. **等価循環の法則** — 物質と性質は消えず循環する。無からの生成はできない。素材・熱・触媒が必要。
2. **属性共鳴の法則** — 水・土・風・火・光・霧。同属性は共鳴、対属性は相殺、光・霧は不安定化しやすい。
3. **安定度の法則** — 混合・加熱・時間で安定度が下がる。閾値以下で失敗・残渣化・暴走。技術で抑制可能。
4. **知識の門の法則** — 未発見素材・未知反応は意図的に使えない。偶然の発見は再現と記録を経て初めて知識になる。未検証仮説と確認済み発見を区別する。
5. **代償の残響の法則** — 強い変換ほど残響（副生成物・疲労・環境変化）を残し、それが後の歴史に影響する。

実験記録には実験ID・実施者・日時・素材・条件・結果・再現性・既存法則との整合性・用途を残す（stories/research/）。
発見があっても生産能力・価格・知識伝播がなければ社会にすぐ普及しない。
