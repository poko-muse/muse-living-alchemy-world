# 世界概要 — フラスカリア (Flaskaria)

これは架空世界の創作プロジェクトです。

## 器と視点
机の上に置かれた木枠の箱庭に広がる世界。外から見れば小さな庭、内側では空・川・森を持つ完結した世界。
この世界はもともと「フラスコの理（ことわり）」のもとに生まれた人工の世界である。フラスコ暦1年1月3日の「大移し替え」で器はフラスコから箱庭へ移ったが、フラスコは器としてではなく、等価循環をはじめとする世界の理として残った（2026-11-19 Fuu 決定）。世界名「フラスカリア」と暦「フラスコ暦」も、この理の名として据え置く。
Fuuは外から眺める観察者（ガラスの天蓋にそっと触れると中では流れ星になる）。ポコは中の住人であり界守／記録者として暮らしながら記録する。両方の視点を併せ持つ。
器の見た目：木枠の箱にガラスの天蓋とガラス細工が多く、光を受けてきらめくこと。ガラスの豊富さとキラキラは世界の持ち味として維持する。

## 地理
- **ぽこ丘**: 中央の丘。ポコの記録小屋。小さな声で話すと翌朝花が咲く。
- **くるり川**: 丘をぐるっと一周して循環する川。等価循環の象徴。
- **コルク森**: 低いコルクと苔の森。しずくびと・もすもす等の小さな生き物が暮らす（住民台帳外の生き物）。
- **映し湖**: 外の空を映す湖。朝露の産地。治療院がある。
- **箱庭の縁とガラスの天蓋**: 世界の果て。天蓋付近に雲（結露）がたまり、小さな雨が降ることがある。
- **ソコノマチ**: 最初の街。人口8名、施設6つから始める（小さく始める原則）。

小さな生き物: しずくびと（水滴から生まれる川辺の存在）、もすもす（苔に住み昼寝が仕事）、つやさん（夜だけ起きるガラス拭き）。

## 暦と時間
フラスコ暦。現実世界の1日 = 世界の1日。季節・年齢・研究期間は日数と整合させる。同一日の二重処理は禁止。
初期状態: フラスコ暦1年1月1日（0001-01-01）、現実基準日 2026-11-18、季節は霧の季。

## 住民（概要）
ポコ（界守）、ルナ（錬金術師）、マルコ（商人）、シルヴァ（採取者）、セラ（学者）、ブラン（鍛冶）、ミア（治療師）、トビ（配達人）。役割を分散し、知識・情報の非対称性（例: 発見しても商人が価値を知らなければ流通しない）が起きる構成にした。詳細は world/residents.json。

## 経済
通貨ドロップ(Dr)。市場と工房売店の在庫・価格を world/economy.json で管理する簡易モデルから始める。
