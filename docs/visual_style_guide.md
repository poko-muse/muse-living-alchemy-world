# フラスカリア ビジュアルスタイルガイド

決定: 2026-11-19（Fuu の参考提示に基づく）。参考は「文法」のみ借り、デザインは全てフラスカリアのオリジナルとする。

## 参考と方向性
- アトリエシリーズのアイテム図鑑のようなイラスト感を土台に、もう少し丸みを帯びた可愛さ。
- 参考: キュイジニア（Cuisineer）— 丸いちびキャラ、ツヤのある可愛い食べ物イラスト、料理図鑑画面（中央に大きく＋名前リボン＋後光）、俯瞰の丸いジオラマ街。

## アイテムのビジュアル方針（2026-11-19 Fuu 提示・正式採用）
- 基本テイスト: 『キュイジニア』のような丸みのある、かわいらしい手描きイラスト
- 世界観: 『アトリエ』シリーズのような、温かみと幻想性のある錬金術ファンタジー
- 造形: 少しデフォルメされた、ぽってりしたシルエット
- 質感: 柔らかな厚塗り、適度な光沢、手描き感のある輪郭
- 色彩: 鮮やかだけれど優しい色合い
- 統一性: 素材・薬品・道具・料理など、すべて同じ画風で制作
- 最重要: かわいらしさを重視しつつ、錬金術の世界らしい神秘性や素材の魅力を失わないこと。
- 基準見本: assets/visual-samples/reference_item_design_sample.jpg（Fuu 提示のアイテムデザインサンプル）、場面絵の基準: reference_poko_workshop.jpg（工房のポコ、短首・丸体型）。

## 仕様
- 形: 輪郭は柔らかく全て丸み。キャラクターは 2〜2.5 頭身のちび体型。
- 色: セージグリーン×桃色（ポコ色）を基調に、クリーム色とガラスの水色。名前リボンは青ではなくセージグリーンを世界の印とする。
- 素材/調合品の見せ方: 羊皮紙ふうカードの中央にアイテムを大きく、後光とキラキラ、ツヤのある質感。図鑑画面のリボンと名前文字は生成画像に描かせず、サイト側の HTML/CSS で重ねる（文字化け防止と多言語・改訂容易性のため）。生成するのはアイテム本体と背景まで。
- 街と地図: 俯瞰ジオラマ風。丸い木、丸い屋根。
- モーション（サイト）: アイテムのふわふわ浮遊、キラキラ粒子、リボンの揺れ、天気連動の演出（霧・光・星）を CSS/SVG で軽量に。
- 禁止: 実在ゲームのキャラクター・料理・ロゴ等の直接の模倣。画風の特徴（丸さ、ツヤ、図鑑構図）のみを借りる。

- sample_rec002_lamp_oil_encyclopedia.webp — 調合品「霧よけランプ油」の図鑑画面。セージグリーンの無地リボン、後光、左端サムネイル列まで仕様どおり。
- sample_poko_chibi.webp — ポコのちびポートレート。現行アバター（二足歩行・セージグリーン×桃色・少し長い首・角2本）を保持し、小さな丸フラスコを持つ。

## v2 修正（2026-11-19、Fuu の指摘）
- v1 は「パステルすぎる」→ 彩度とコントラストを上げる。鮮やかな飽和色、濃い輪郭、ゲームイラストらしい強さにする。パステル・水彩の淡さは禁止。
- v1 のポコは首が伸びて首長竜化した → ちび体型では首は短く太く、大きな頭が丸い体にほぼ直接乗る形にする。現行アバターの「少し長い首」は等身の高い表現での特徴で、ちび化では短縮する。
- v2 見本: sample_v2_mat007_mist_crystal.webp / sample_v2_rec002_lamp_oil_encyclopedia.webp / sample_v2_poko_chibi.webp（いずれも彩度UP版、ポコは短首で再生成）。

## 量産時の運用
- 固定資産（住民ポートレート、素材アイコン、地図）は一括生成して site/assets に配置。
- 日々の場面絵は作わず、週次新聞の1枚と、発見・祭り等の特別な出来事の記念絵に絞る（リポジトリ肥大と画風ブレの防止）。
- 生成後は必ず目視確認し、画風・キャラクター形状が仕様から外れたら再生成する。

## 追記（2026-11-19）新テイストへの移行

経緯: バッチ3の火種の種の描き直しで、修正文言（「大まかな厚塗り」「マットに」）が会話全体の画風をマット寄りに引っ張るドリフトが発生。その対処として新しい会話＋参照シート再添付で描かれた火種の種（袋から溢れる種、炎のタグ、芽吹いた種、強いツヤとキラキラ）を Fuu が最も気に入り、**全点をこの新テイストで揃え直す**ことを決定した（2026-11-19 夕）。上記の Fuu 原文方針は変更せず、画風の細部は本追記が優先する。

新テイストの特徴:
- **輪郭**: はっきりした手描きの輪郭線（旧方針の「手描き感のある輪郭」を強めたもの）
- **質感**: 強めのツヤと、キラキラの星の輝きを積極的に使う。マット・水彩の淡さは不可
- **色彩**: 鮮やかで温かい色。彩度は高めに保つ
- **小物**: 素材の魅力を示す小物（袋・タグ・容器など）の使用可。火種の種の「炎マークのタグ」のように、素材の性質を絵で伝える工夫を歓迎する（ただし文字は入れない。絵柄のマークのみ可）
- **継承するもの**: ぽってりしたデフォルメ造形、柔らかな厚塗り、丸みのある可愛さ、神秘性を失わないこと、単品・クリーム背景・文字なしの形式は従来方針どおり

基準見本: `assets/visual-samples/reference_style_v2_hidane.jpg`（新テイストの火種の種）。以後、全点（バッチRで素材・調合品を揃え直し、住民・地図も新テイストで制作）をこの絵柄で統一する。旧テイストの制作済み分は、バッチRの採用に合わせて順次差し替える。
